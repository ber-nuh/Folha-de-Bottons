# Folha de Bottons

Aplicativo para Windows para organizar artes de bottons, montar folhas para impressão e exportar arquivos. **Idealizado por Ber-nuh.**

## Abas do programa

### Bottons
Aba principal para selecionar imagens, detectar e organizar bottons, ajustar dimensões e espaçamentos, visualizar a folha e preparar a impressão/exportação.

![Aba Bottons — tela inicial](docs/images/aba-bottons-inicial.png)

![Aba Bottons — exemplo de folha montada](docs/images/aba-bottons-exemplo.png)

### Quantidades
Permite agrupar bottons por tipo e definir quantas unidades de cada modelo devem ser preparadas.

![Aba Quantidades](docs/images/aba-quantidades.png)

### Configurações
Reúne as opções de aparência, tamanho do texto, alto contraste, áudio e verificação de atualizações.

## Impressão

Ao imprimir, selecione **100% / Tamanho real** para evitar que a escala da página altere as medidas dos bottons.

## Atualizações

Quando disponível, a verificação de atualizações informa sobre uma versão mais recente e oferece acesso ao instalador. A verificação depende de conexão com a internet.
