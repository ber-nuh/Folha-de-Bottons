# Folha de Bottons

Aplicativo para Windows para organizar artes de bottons, montar folhas para impressão e exportar arquivos.

**Idealizado por Ber-nuh.**

## Código-fonte

O código está na pasta Folha-de-Bottons/.

- Instruções e detalhes: Folha-de-Bottons/README.md
- Dependências Python: Folha-de-Bottons/requirements.txt
- Notas do projeto: Folha-de-Bottons/NOTAS.md

## Importante

Este repositório contém o código-fonte, não um instalador pronto para o usuário final. Alguns recursos podem depender de arquivos de mídia/modelos que não foram incluídos no envio inicial. Confira o README da pasta do projeto antes de executar ou compilar.

O verificador de atualizações automáticas e o fluxo de baixar uma nova versão e pedir confirmação antes de instalar ainda precisam ser implementados e testados.
